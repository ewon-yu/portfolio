# Ewon — Portfolio

UI 디자이너 포트폴리오 웹사이트.

## Stack

- Vite + React 19 + TypeScript
- [Astryx](https://astryx.atmeta.com/) 디자인 시스템 (dark 고정)
- react-router-dom

## Dev

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

## 구조

- `src/data/` — 콘텐츠 (profile, cases)
- `src/routes/` — 페이지 (Home / Work / CaseDetail / Contact)
- `src/routes/cases/` — 개별 케이스 스터디 (BORA Portal 등)
- `public/work/` — 케이스 이미지

진행 상황은 `STATUS.md` 참고.
